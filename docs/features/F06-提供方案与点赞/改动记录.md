## 2026-11-26 · v0.1.0 · 新增

**摘要**：新增"提供方案"能力，把产品从"选项投票"扩展为"众包解法库"；方案可点赞、可被采纳。

**实现内容**
- `POST /api/posts/{id}/solutions`：内容 ≤500 字、过内容安全、校验帖存在
- `GET /api/posts/{id}/solutions`：返回点赞数、我的点赞态、是否已采纳、作者星星与代表场景标签
- `POST /api/solutions/{id}/like`：切换式点赞，用"插入捕获唯一键冲突"实现，规避检查-写入竞态
- `dv_solution` 冗余 `like_count` 便于排序；`dv_solution_like` 唯一索引防重复赞
- 前端详情页方案区：输入提交、点赞切换、采纳角标、作者星星徽标、场景标签

**新增文件**
- `backend/src/main/java/com/lukou/decision/entity/Solution.java` / `SolutionLike.java`
- `backend/src/main/java/com/lukou/decision/mapper/SolutionMapper.java` / `SolutionLikeMapper.java`
- `backend/src/main/java/com/lukou/decision/dto/SolutionReq.java` / `SolutionVO.java`
- `backend/src/main/java/com/lukou/decision/service/SolutionService.java`
- `backend/src/main/java/com/lukou/decision/controller/SolutionController.java`

**涉及/修改文件**
- `backend/src/main/resources/db/schema.sql`（`dv_solution`、`dv_solution_like`）
- `miniprogram/pages/detail/detail.js` / `.wxml` / `.wxss`
- `miniprogram/utils/api.js`（`solutions` / `addSolution` / `likeSolution`）

**验证方式**
- 冒烟脚本：提交方案成功、点赞后 `likeCount = 1`、重复点赞回落为 0、列表能读到 `authorStars` 与 `authorSceneTag`
- 后端编译通过，前端静态校验通过

**已知缺陷（尚未修复，已记入功能说明第 9 节）**
- `SolutionService.list` 的比较器末尾多了一次 `.reversed()`，导致已采纳方案被排到列表末尾而非置顶
- `toVO` 存在 N+1 查询（每条方案 3 次 SQL）
