## 2026-11-26 · v0.1.0 · 新增

**摘要**：采纳机制与星星/场景标签体系上线，星星只能由采纳产生，不可自封。

**实现内容**
- `POST /api/posts/{id}/adopt`：仅发起者可操作，一帖一采纳，已采纳方案再次调用为取消
- 采纳即 `awardCredit`：按帖子场景给作者 +1 星；场景为空归入「其他」
- 换采纳时自动 `revokeCredit` 原方案作者，减到 0 删除场景记录
- 星星读取并入 `GET /api/users/me`（`stars` + `starTags`），方案列表带 `authorStars` / `authorSceneTag`
- 前端采纳前二次确认，提示"作者将获得一颗星星及对应领域标签"

**验证方式**
- 冒烟脚本断言：非发起者采纳返回 403；发起者采纳后方案 `adopted = true`；作者 `stars` 由 0 变 1；`starTags` 出现"考研"场景
- 数据库核对：`dv_user_credit` 生成对应 `(user_id, scene)` 行且 `stars = 1`
- 后端编译通过

**设计取舍**
- 星星不做 `dv_user.stars` 冗余字段，改为实时 `SUM`。当前量级无性能问题，且避免双写不一致；量大后再加冗余（已在项目文档 I-04 记录）
