## 2026-11-26 · v0.1.0 · 新增

**摘要**：回访机制上线——发布即埋 3 个月后的时间点，到期后发起者回填结局，形成"决策 → 结果"数据链。

**实现内容**
- `PostService.create` 内自动创建回访计划（`due_at = now + 3 月`，`answered_at` 为空），与建帖同事务
- `POST /api/posts/{id}/follow-up`：仅发起者可填，标签枚举校验，同帖覆盖更新并刷新 `answered_at`
- `GET /api/follow-ups/pending`：到期未填列表（`answered_at IS NULL AND due_at <= now`，升序 20 条）
- 详情接口透出结局：`chosenOptionId` / `outcome` / `outcomeNote` / `outcomeSlot`
- 前端详情页回访区（仅发起者可见）+ 结局展示区；"我的"页待回访清单

**验证方式**
- 冒烟脚本断言（4 项）：非发起者提交被拒、发起者提交成功、详情返回结局字段、`/follow-ups/pending` 可调用
- 数据库核对：`dv_follow_up.answered_at` 非空，`chose_option_id` 与所选选项一致

**待补的关键能力（已记入功能说明第 9 节）**
- 无微信订阅消息主动提醒，到期只能被动查看，回访率无保障
- 一帖一条记录，无法支撑 3 个月 / 1 年 / 3 年的多轮回访
