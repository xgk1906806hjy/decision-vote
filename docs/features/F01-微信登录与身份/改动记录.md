## 2026-11-27 · v0.1.1 · 新增

**摘要**：补上用户主动登录入口与微信头像昵称能力。此前只有静默登录、昵称随机、头像永远为空，"登录"这件事对用户不可见。

**实现内容**
- 新增 `pages/login` 登录页：微信一键登录（`wx.login`）+ 协议勾选 + 头像/昵称选填（`chooseAvatar` / `type="nickname"`）
- 新增 `POST /api/files/avatar`：multipart 上传，只收 jpg/png/webp，≤2MB，**按文件头判类型**（扩展名与 Content-Type 不可信），文件名服务端生成
- 头像落盘 `uploads/avatar/yyyyMM/`，`WebConfig` 映射 `/uploads/**` 静态访问，库里存相对路径（换域名不用刷数据）
- `UploadProperties`：`UPLOAD_DIR` / `UPLOAD_PUBLIC_BASE` / `UPLOAD_AVATAR_MAX_MB` 三个配置项
- `spring.servlet.multipart` 限 2MB，超限由 `GlobalExceptionHandler` 转成"图片太大了"而非 500
- 「我的」页 401 不再显示"加载失败"，改为 `viewState='guest'` 显示登录引导卡
- 「编辑资料」新增换头像：`chooseAvatar` → 上传 → PUT 资料，先传后提交，上传失败不覆盖昵称/简介
- `api.js` 新增 `uploadAvatar()`、`fileUrl()`（相对路径拼域名），`login()` 支持带昵称

**修改文件**
- 后端：`controller/FileController`（新）、`config/UploadProperties`（新）、`config/WebConfig`、`common/GlobalExceptionHandler`、`application.yml`
- 前端：`pages/login/*`（新）、`pages/profile/profile.js/.wxml/.wxss`、`utils/api.js`、`app.json`
- 文档：本文件、`功能逻辑说明.md`、`docs/02`、`README`

**验证**
- 上传 74 字节 PNG → `path=/uploads/avatar/202611/xxx.png`，`GET` 该路径 200 / `image/png`
- 上传文本文件 → 400「只支持 jpg / png / webp 图片」；未登录上传 → 401
- `PUT /users/me {avatar}` → `GET /users/me` 返回同一路径
- 冒烟脚本新增 5 项头像断言（未登录拒绝、上传成功、静态可访问、非图片拒绝、写回资料）

## 2026-11-26 · v0.1.0 · 新增

**摘要**：建立微信静默登录与 JWT 身份体系，支持游客浏览与登录态操作并存。

**实现内容**
- `POST /api/auth/login`：code → openid → 自动建号 → 签发 JWT（HS256，720 小时）
- `WxApiService` 双模式：`WX_MOCK=true` 用 `mock_ + abs(code.hashCode())` 造稳定 openid；`false` 走 `jscode2session`
- 首次登录随机昵称："6 种前缀 + 3 位数字"
- `AuthInterceptor` 只解析不拦截，接口用 `UserContext.require()` / `get()` 自行声明鉴权级别
- 前端 `api.js` 统一注入 `Authorization: Bearer`，401 自动清 token

**涉及文件**

- `backend/src/main/java/com/lukou/decision/service/AuthService.java`
- `backend/src/main/java/com/lukou/decision/service/WxApiService.java`
- `backend/src/main/java/com/lukou/decision/util/JwtUtil.java`

**验证方式**
- 冒烟脚本 `scripts/smoke_test.py` 用两个不同 code 登录，拿到两个独立 userId 与 token，验证不串号
- `mvn -DskipTests compile` 通过
- mock 模式登录同一 code 两次，`userId` 一致、`isNew` 第二次为 `false`
