## 2026-11-27 · v0.1.4 · 优化

**摘要**：补 USB 直连方案（`adb reverse`），并让隧道脚本自动写回 `config.js`；隧道域名轮换从「改代码」降级为「无感」。

**背景**：上一条上线后实测，`localhost.run` 免费版 **12–18 分钟**就轮换一次域名（日志 `tunnel xxx.app.lhr.life removed` + 新域名），比预估的 20 分钟更频繁，纯隧道方案不可用。用户确认手机走**移动流量**，与电脑无任何网络交集，因此：

- 内网 IP 永远不可达（`time out` 是 SYN 被丢弃）
- 免费隧道必然轮换（`localhost.run` 12–18 分钟 / `cpolar` 24 小时）
- 固定二级子域名需付费

**实现内容**
- 新增 `scripts/usb.sh`：`adb reverse tcp:8080 tcp:8080`，把手机的 `localhost:8080` 转发到电脑 8080。走 USB 不过网络，零延迟、不轮换、免注册。脚本自动在 PATH / `D:\Program Files\platform-tools` / `%LOCALAPPDATA%\Android\Sdk` 等处查找 adb；无设备时给出「线是否只能充电 / USB 调试是否打开 / 是否点了允许」三项排查而不是抛英文错误
- `scripts/tunnel.sh` 增强：捕获到新域名后用 `sed` **自动写回 `config.js` 的 `HOSTS.tunnel`**，并提示「手机上改地址」的最快路径
- 配套使用 `v0.1.3` 的手动地址入口，USB 方案只需填 `http://localhost:8080`

**修改文件**
- 新增 `scripts/usb.sh`
- `scripts/tunnel.sh`、`miniprogram/config.js`（隧道地址同步为当前域名）
- `README.md`、`docs/02-项目文档.md`（3.5、目录树）、本文件

**验证**
- `bash scripts/usb.sh` 无设备时输出三项排查提示、退出码 1；有设备时的 `adb reverse` 为标准功能
- `sed` 改写 `config.js` 后：中文注释完好、UTF-8 无 BOM、`node --check` 通过，且不会误伤 `PROBE_TIMEOUT` 里的 `tunnel: 8000`（正则只匹配 `tunnel: 'https://…'`）
- `adb version` → 1.0.41 / 34.0.4，adb 位于 `D:\Program Files\platform-tools\platform-tools\adb.exe`

**踩坑记录**
- 隧道地址写死在 `config.js` 会被频繁轮换打脸，正确做法是「脚本自动写回 + 小程序内可手改」双保险，而不是追求固定域名
- `git push` 期间反复报 `schannel: failed to receive handshake`，与代码无关，是网络链路问题，重试即可

## 2026-11-27 · v0.1.3 · 优化

**摘要**：小程序内新增「服务器地址」入口，隧道域名变更后在手机上粘一次即可，不再需要改代码 + 重新编译。

**背景**：免费隧道做不到永久固定域名。实测 `localhost.run` 连接约 18 分钟后域名轮换（日志打印 `tunnel xxx removed` + 新域名），小程序随即全部超时。备选方案逐个验证：

| 方案 | 结论 |
|---|---|
| Cloudflare 快速隧道 | `429`，账号无关隧道被限流 |
| localtunnel（`lukou-dv.loca.lt`） | 客户端连不上服务端，长期 `503 Tunnel Unavailable` |
| serveo（免注册） | 可通，但随机域名且固定子域名需注册 SSH key，免费版有浏览器警告页风险 |
| cpolar 免费版 | 可用、国内快，但**域名每 24 小时自动变更**，固定二级子域名需付费 |

既然「域名不变」在免费方案里无解，就把「换域名」的成本降到最低。

**实现内容**
- `api.js` 新增手动地址机制：storage key `dv_api_manual`，优先级 **手动 > ENV 指定 > auto 探测**；`setManualHost('')` 即清除回自动；填手动地址时**不做探测**，省掉首屏等待
- `profile` 页新增「服务器地址」卡片：显示当前生效地址 + `手动/自动` 徽标，点击用 `wx.showModal({editable:true})` 输入，校验必须以 `http(s)://` 开头，保存后自动下拉刷新
- 卡片放在**所有 viewState 之外**（`block wx:else` 之前）：地址填错时页面会停在 `error`/`guest` 态，入口若在 ready 分支里就再也进不去，形成死锁
- `prod` 环境不渲染该卡片

**修改文件**
- `miniprogram/utils/api.js`（手动地址、`getHost`/`getManualHost`/`setManualHost` 导出）
- `miniprogram/pages/profile/profile.js` / `profile.wxml` / `profile.wxss`
- `README.md`、`docs/02-项目文档.md`（3.5）、本文件

**验证**
- `node --check` 3 个文件通过；静态校验：WXML 标签全配对、19 个事件方法全部存在、模板引用的 data 字段全部已声明
- mock 测试：手动地址优先且探测次数为 0；尾斜杠自动裁剪；清除后回到 auto 并选中隧道地址；`BASE_URL` 拼接正确
- 后端冒烟 51 项全通过（本次未改后端）

## 2026-11-27 · v0.1.2 · 优化

**摘要**：请求层改成「自动选路」，局域网连不上时自动降级到公网隧道，真机联调不再依赖手机与电脑同网段。

**背景**：真机日志里 11 个接口全部 `request:fail fail:time out`，耗时 1.5s 左右断掉。排查结果：

- 后端在跑（`netstat` 显示 `0.0.0.0:8080 LISTENING`，本机 `curl http://192.168.100.89:8080/api/health` → 200）；
- Windows 防火墙 Private/Public 档实际是**关闭**状态，规则不是瓶颈；
- 该网段为共享网络（ARP 表有 40+ 台设备），典型有客户端隔离；
- 真机调试面板右侧「连接方式」显示「**其他**」而非「局域网」，说明手机不在电脑局域网内。

即请求根本没到电脑（`time out` 是 SYN 被丢弃，不是被拒绝），改 IP 无解。

**实现内容**
- `config.js` 新增 `ENV='auto'` 与 `AUTO_ORDER=['lan','tunnel']`、`HOSTS.tunnel`
- `api.js` 新增选路逻辑：
  - `probeHost()`：请求 `host + /api/health`，`code===0` 视为可用，超时 3s；
  - `probe()`：并发探测所有候选，**第一个成功者获胜**；
  - `resolveBase()`：单例 Promise，11 个并发请求只触发一次探测；结果写 storage 缓存；
  - `resetBase()`：请求失败时清空缓存，下次请求重新选路（换 WiFi、IP 变化、隧道断线都能自愈）；
  - `fileUrl()` 改用当前生效地址拼接；`uploadAvatar()` 同样先 `resolveBase()`；
  - 全部候选失败时提示列出试过的地址：`网络异常（都连不上：a / b）`。
- 新增 `scripts/tunnel.sh`：先探活后端，再用 `ssh -R` 建隧道（localhost.run，免注册），自动从输出里提取 `https://*.lhr.life` 并打印填写指引。

**修改文件**
- `miniprogram/config.js`、`miniprogram/utils/api.js`
- 新增 `scripts/tunnel.sh`
- `README.md`（4. 打开小程序：ENV 表格 + 客户端隔离说明 + 报错自查表）、`docs/02-项目文档.md`（3.5、目录树）、本文件

**验证**
- `node --check` 通过；mock `wx.request` 跑四个场景：只有隧道通→选隧道；并发三次 `resolveBase()` 共享同一结果；两者都通→优先局域网；全不通→`code=-1` 且提示列出两个地址
- 隧道实测 `curl https://1bef59eef09928.app.lhr.life/api/health` → 200（延迟 1.5–4.9s）
- 后端冒烟 51 项全通过（本次未改后端）

**踩坑记录**
- Cloudflare 快速隧道（`cloudflared tunnel --url`）在本机返回 `429`，账号无关隧道被限流；且 GitHub 直连下载 3 分钟仅 760KB，最终换用 `ssh -R` 方案（零安装、免注册）。
- 免费隧道域名会周期性轮换，仅适合联调，不能写进正式环境。

## 2026-11-27 · v0.1.1 · 优化

**摘要**：后端地址从 `api.js` 里硬编码的 `localhost` 抽到独立配置文件，真机不再必然「网络异常」。

**背景**：真机上 `http://localhost:8080` 指向手机自己，所有请求必然失败；改地址要动请求层源码，容易漏改。

**实现内容**
- 新增 `miniprogram/config.js`：`ENV`（`dev`/`lan`/`prod`）+ `HOSTS` + `TMPL_FOLLOW_UP`
- `utils/api.js` 改为 `require('../config')`，`BASE_URL` 与模板 ID 都从配置读，并对外暴露 `ENV`
- 请求失败文案改为带目标地址：`网络异常（连不上 192.168.x.x:8080）`，同时 `console.error` 打出完整 URL 与 `errMsg`
- 文档补齐真机连通三要素（同 WiFi / 内网 IP / 防火墙 8080）

**修改文件**
- 新增 `miniprogram/config.js`
- `miniprogram/utils/api.js`（头部常量、`fail` 回调、导出）
- `README.md`、`docs/02-项目文档.md`（3.5 启动、12.8 发布）、本文件

**验证**
