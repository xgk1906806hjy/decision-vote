## 2026-11-26 · v0.1.0 · 新增

**摘要**：回访数据沉淀为可检索案例库，并提供相似案例推荐供发起决策前参考。

**实现内容**
- `GET /api/cases`：已回访决策列表，支持场景筛选、关键词（标题/描述）搜索、分页
- `GET /api/cases/similar`：同场景 + 关键词打分推荐，默认 5 条、上限 20
- 结局中文化统一在 `CaseService.OUTCOME_LABEL`（worth/regret/watching → 值得/后悔/观察中）
- 前端案例库页：场景 chip、搜索框、清空、分页、下拉刷新、区分"完全空"与"筛选空"两种空态
- 发起页选场景后自动拉 3 条相似案例，失败静默不阻塞发布

**新增文件**
- `backend/src/main/java/com/lukou/decision/controller/CaseController.java`
- `backend/src/main/java/com/lukou/decision/service/CaseService.java`
- `backend/src/main/java/com/lukou/decision/dto/CaseVO.java`
- `miniprogram/pages/cases/cases.js` / `.wxml` / `.wxss` / `.json`

**涉及/修改文件**
- `miniprogram/app.json`（注册为 tabBar 页）
- `miniprogram/pages/create/create.js`（`loadSimilarCases`）
- `miniprogram/utils/api.js`（`cases` / `similarCases`）

**验证方式**
- 冒烟脚本断言（3 项）：回访后可查到案例、`outcomeLabel` 正确、`/cases/similar` 可调用并返回列表
- 后端编译通过，前端静态校验通过

**修复记录**
- 冒烟脚本调用中文关键词接口时报错，定位为测试脚本未做 URL 编码，补 `urllib.parse.quote` 后通过（业务代码本身无问题）

**已知缺陷（尚未修复，已记入功能说明第 9 节）**
- `list` 为全量内存过滤 + 内存分页，案例量上千后性能会明显退化，需下推为 SQL 分页
- 相似度按单字符命中计分，语义匹配能力弱
