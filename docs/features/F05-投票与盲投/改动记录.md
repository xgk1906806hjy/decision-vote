## 2026-11-26 · v0.1.0 · 新增

**摘要**：投票与盲投机制上线，投票后同一响应内就地揭晓结果。

**实现内容**
- `POST /api/posts/{id}/vote`：状态/截止/选项归属三重校验，唯一约束防重复投票
- 投票成功直接返回 `PostDetailVO`（已揭晓），前端零额外请求即可展开结果
- 盲投判定收敛到 `PostService.buildCards`，列表与详情共用；新增 `PostCardVO.blind` 供前端判断
- 盲投时选项 `count/percent` 强制归零，但 `totalVoteCount` 保留真实人数
- 前端详情页投票区：选中高亮 → 提交 → 进度条就地生长 + 轻震动 + Toast

**涉及文件**
- `backend/src/main/java/com/lukou/decision/controller/VoteController.java`
- `backend/src/main/java/com/lukou/decision/service/VoteService.java`
- `backend/src/main/java/com/lukou/decision/service/PostService.java`（`buildCards` / `copy`）
- `backend/src/main/java/com/lukou/decision/dto/PostCardVO.java` / `PostDetailVO.java` / `OptionVO.java`
- `backend/src/main/java/com/lukou/decision/mapper/VoteMapper.java`
- `backend/src/main/resources/db/schema.sql`（`uk_post_user` 唯一索引）
- `miniprogram/pages/detail/detail.js` / `.wxml` / `.wxss`

**验证方式**
- 冒烟脚本断言（6 项）：未投票 `blind=true` 且票数为 0、参与人数 >0、投票后 `blind=false` 且票数与百分比可读、`myOptionId` 正确、重复投票被拒
- 后端编译通过，前端静态校验通过

**修复记录**
- 盲投初版误用 `vo.isAuthor()` 判断发起者身份，而该字段在 `buildCards` 阶段尚未赋值，导致发起者在列表页也看不到结果。改为 `Objects.equals(post.getUserId(), userId)` 直接比较
- 详情页初版在投票后整页重新加载，揭晓有闪烁。改为用接口返回的 `post` 就地 `setData`，只重拉方案列表
