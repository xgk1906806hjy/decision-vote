## 2026-11-26 · v0.1.0 · 新增

**摘要**：首页信息流上线，卡片级盲投规则与批量组装落地。

**实现内容**
- `GET /api/posts/feed`：时间倒序 + 场景筛选 + 分页（`size` 上限 50）
- `buildCards` 批量组装：选项、票数统计、评论数、我的投票、作者信息各一次查询，**列表 50 条固定 5 条 SQL**
- 盲投判定下沉到 `buildCards`，列表与详情共用同一套规则，避免两处逻辑漂移
- 卡片返回 `blind` 布尔字段，前端据此决定渲染进度条还是"N 人参与"
- 新增 `myPosts` / `myVoted` 两个个人维度列表接口（`myVoted` 用投票时间保序回捞帖子）
- 前端首页：8 场景 chip 筛选、下拉刷新、上拉加载、四态视图、右下角发起入口

**涉及文件**
- `backend/src/main/java/com/lukou/decision/controller/PostController.java`
- `backend/src/main/java/com/lukou/decision/service/PostService.java`（`feed` / `myPosts` / `myVoted` / `buildCards`）
- `backend/src/main/java/com/lukou/decision/dto/PostCardVO.java`（新增 `blind` 字段）
- `backend/src/main/java/com/lukou/decision/mapper/VoteMapper.java`（`statByPostIds`）
- `backend/src/main/java/com/lukou/decision/mapper/CommentMapper.java`（`countByPostIds`）
- `miniprogram/pages/index/index.js` / `.wxml` / `.wxss` / `.json`
- `miniprogram/app.wxss`（场景 chip 等通用样式上提）

**验证方式**
- 冒烟脚本断言：未投票用户 `blind = true` 且所有选项 `count = 0`，同时 `totalVoteCount > 0`
- 后端编译通过；前端 JSON/JS/WXML 静态校验通过

**修复记录**
- 修复盲投判断误用 `vo.isAuthor()` 的问题：`author` 标志只在 `detail()` 中赋值，`buildCards` 阶段尚未设置，导致列表页对发起者也隐藏了结果。改为直接比较 `post.getUserId()` 与当前用户
