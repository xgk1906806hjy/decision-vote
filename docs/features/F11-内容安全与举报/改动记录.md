## 2026-11-27 · v0.1.3 · 新增（举报处置后台 + 建议举报）

**摘要**：举报从“只能提交”补到“可查看、可隐藏、可驳回”，并给每条建议加了举报入口。

**实现内容**
- `dv_report` 新增 `action` / `handled_at` 字段与 `idx_handled_created` 索引，提供升级脚本
- `GET /api/admin/reports`：按 `handled` 过滤、分页、批量回填举报人/目标摘要/目标状态
- `POST /api/admin/reports/{id}/handle`：`hide` 隐藏内容，`dismiss` 驳回；已处理记录拒绝重复操作
- 决策帖 `hide` 走逻辑删除，建议 `hide` 写 `status=0`
- 静态后台页 `/admin/reports.html`：输入 `ADMIN_TOKEN` 后查看和操作，令牌存 `sessionStorage`
- 详情页每条建议新增「举报」入口，复用 `reportTarget` 与原因选择

**涉及文件**
- `backend/src/main/java/com/lukou/decision/config/AdminProperties.java`（新增）
- `backend/src/main/java/com/lukou/decision/controller/AdminReportController.java`（新增）
- `backend/src/main/java/com/lukou/decision/service/ReportAdminService.java`（新增）
- `backend/src/main/java/com/lukou/decision/dto/ReportVO.java` / `HandleReportReq.java`（新增）
- `backend/src/main/java/com/lukou/decision/entity/Report.java`
- `backend/src/main/resources/db/schema.sql` / `db/upgrade/2026-11-27-report-handling.sql`
- `backend/src/main/resources/static/admin/reports.html`（新增）
- `miniprogram/pages/detail/detail.js` / `.wxml` / `.wxss`
- `backend/src/main/resources/application.yml`（`ADMIN_TOKEN`）

**验证方式**
- 管理员列表返回 4 条待处理举报；错误令牌返回 401
- 对举报 id=4 执行 `hide`：接口成功，`dv_report.handled=1`、`action=hide`、`handled_at` 写入；`dv_post.deleted=1`，详情接口返回 404

## 2026-11-26 · v0.1.1 · 新增（举报接口上线）

**摘要**：补齐举报的 Service 与 Controller，并在详情页加入口。举报从"只有表和 Mapper"变为真正可用，解掉 UGC 过审的阻塞项。

**实现内容**
- `POST /api/reports`：入参 `{targetType: post|comment, targetId, reason(≤255)}`，写 `dv_report`
- 四条校验，按顺序执行：类型白名单 → 目标存在（帖/建议分别查）→ 不能举报自己发布的内容 → 同一用户对同一目标只记一次
- `handled` 初始为 0，留给后台人工处理；当前不提供处理接口
- 前端详情页正文卡右下角「举报该内容」，`wx.showActionSheet` 选原因（违法违规内容 / 色情低俗 / 广告营销 / 人身攻击 / 虚假信息）后提交，失败时把后端 `msg` 直接 toast 出来
- `utils/api.js` 新增 `report(data)`

**新增文件**
- `backend/src/main/java/com/lukou/decision/dto/ReportReq.java`
- `backend/src/main/java/com/lukou/decision/service/ReportService.java`
- `backend/src/main/java/com/lukou/decision/controller/ReportController.java`

**涉及/修改文件**
- `miniprogram/pages/detail/detail.js`（`onReport` 方法 + `reporting` 状态位防重复点击）
- `miniprogram/pages/detail/detail.wxml`（正文卡举报入口）
- `miniprogram/pages/detail/detail.wxss`（`.report-row` / `.report-link`）
- `miniprogram/utils/api.js`

**验证方式**

冒烟测试新增 5 项并全部通过：他人举报成功入档、不能举报自己、同内容重复举报被拒、非法类型被拒、目标不存在被拒。已直接查库确认记录落盘，且中文 `reason` 以 utf8mb4 正确存储（`广告营销` = `E5B9BFE5918AE890A5E99480`，4 字符 12 字节）。

**仍未实现**
- 举报处理后台（`handled` 目前永远是 0）
- 建议（comment）维度的前端入口，后端已支持 `targetType=comment`
