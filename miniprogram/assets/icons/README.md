# 图标资产说明

全部图标由 `scripts/gen_icons.py` 程序化生成，不含外部位图素材，改配色或比例后可随时重跑复现：

```bash
python scripts/gen_icons.py
```

## 设计含义

图标符号是**一条路走到分岔口**：

```
        ●        ●        ← 两个可能的去向
         \      /
          \    /
           \  /
            ●             ← 分岔点：必须做出选择
            │
            │
            ●             ← 现在的你
```

底部的大节点是「现在的你」，向上走到分岔点，分成两条方向。它刻意不画"正确答案"——因为本产品的主张正是**重大决策没有标准答案，只有适不适合你**。同一条路分出两个方向，选择权在走的人手上。

符号与产品的三个核心机制同构：起点（现状）→ 分岔（决策）→ 两条路（选项与方案）。

## 配色

与 `app.wxss` 的暖色令牌完全一致，保证图标和界面同源：

| 用途 | 色值 |
|---|---|
| 背景左上（受光面） | `#EA9757` |
| 背景右上 | `#D0672F` |
| 背景左下 | `#C25826` |
| 背景右下（暗部） | `#9B3F18` |
| 符号 | `#FFFFFF` |
| 路的投影 | `#7A3413` |

底部为对角渐变（左上亮 → 右下暗）叠加一层偏左上的柔光，让纯色底有体积感；白色符号带轻微投影，在高对比下仍有浮雕层次。

| 文件 | 尺寸 | 用途 |

## 使用说明

**小程序头像**：微信公众平台 → 设置 → 基本设置 → 小程序头像，上传 `app-icon-144.png`（平台要求 144×144，会再裁成圆形显示）。图标内容在中心安全区内，圆形裁剪不会切到符号。

**tabBar**：已在 `app.json` 中配置 `iconPath` / `selectedIconPath`。tabBar 图标必须是 81×81 的 PNG 且小于 40KB，当前文件均满足（最大 3.2KB）。

**修改配色时**：`gen_icons.py` 顶部的 `C_TL / C_TR / C_BL / C_BR` 与 `draw_tab_icon` 调用处的两个色值需要和 `app.wxss` 同步修改，避免图标与界面脱节。
